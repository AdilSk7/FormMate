# FormMate – Smart Autofill Extension

Chrome/Edge browser extension repository. See [formmate/README.md](./formmate/README.md) for complete details.

## Quick Start
1. Go to `chrome://extensions` (Chrome) or `edge://extensions` (Edge).
2. Enable **Developer mode**.
3. Click **Load unpacked** and select the `formmate` directory.
4. Open `formmate/test-form.html` to test the extension locally!
